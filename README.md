# Biocinoz

Проект по C++: модель замкнутой биологической системы с визуализацией через SFML.

В симуляции есть три типа объектов:

- `Plant` - растения/еда;
- `Herbivore` - травоядные, которые едят растения;
- `Predator` - хищники, которые охотятся на травоядных.

Система работает в 3D-пространстве, а в окне SFML показывается 2D-проекция этого мира с учетом глубины.

## Что реализовано

- базовый класс `Entity`;
- наследование: `Plant`, `Animal`, `Herbivore`, `Predator`;
- структура `Vec3` для координат и перегрузки операторов `+`, `-`, `*`, `+=`, `operator<<`;
- параметры жизни видов: возраст, голод, энергия, размножение, скука, перенаселение;
- сексуальное и асексуальное размножение;
- проверка устойчивости минимум до 1000 итераций;
- графический режим через SFML;
- консольный режим без окна через `--headless`.

## Структура проекта

Код разбит по требованиям лекций: объявления находятся в `.h` файлах с `#pragma once`, реализации методов - в `.cpp` файлах.

```text
src/
  main.cpp              главный файл запуска
  Vec3.h/.cpp           3D-вектор и операторы
  SpeciesConfig.h       параметры отдельного вида
  Entity.h/.cpp         базовый класс сущности
  Plant.h/.cpp          растения
  Animal.h/.cpp         базовый класс животных
  Herbivore.h/.cpp      травоядные
  Predator.h/.cpp       хищники
  World.h/.cpp          логика симуляции
  Renderer.h/.cpp       графика SFML
  RenderParticle.h      вспомогательная структура для отрисовки
```

`main.cpp` не содержит классов и структур. Он только подключает нужные заголовки, создает объект `World` и запускает программу.

## Сборка

Проект использует CMake. SFML подключается автоматически: если библиотека не найдена в системе, CMake скачает SFML 2.6.2 через `FetchContent`.

```bash
cmake -S . -B build
cmake --build build
```

В Visual Studio можно просто открыть папку проекта как CMake-проект и собрать цель `biocinoz`.

## Запуск

Графический режим:

```bash
./build/biocinoz
```

Консольный режим без окна:

```bash
./build/biocinoz --headless
```

Если сборка идет через Visual Studio, исполняемый файл обычно находится в папке:

```text
out/build/x64-Debug/biocinoz.exe
```

## Управление в окне

- `Space` - пауза/продолжить;
- `Up` - ускорить симуляцию;
- `Down` - замедлить симуляцию;
- `Esc` - закрыть окно.

## Условие завершения

Симуляция пытается прожить до 5000 итераций. Если растения, травоядные или хищники полностью исчезают, система считается погибшей.
